MotionLife 2.0 — Architecture

VLM router finds every motion · specialized models extract it · mesh-warp applies it · VLM judge scores & auto-tunes

VLM (Claude) — the brain

  • • Router: finds every motion in a clip (multi-motion), classifies each
  • • Auto-labeler: names artwork objects (retires hand-labeling)
  • • Judge: scores the applied motion, returns fix deltas
  • • Understands & decides — never produces the motion itself

ML models — the muscle

  • • SAM 2: precise per-object masks from VLM boxes
  • • SEA-RAFT: fast, clean optical flow
  • • CoTracker3: real long-range point trajectories
  • • Distill: keeps bulk + residual → travel and texture

Application + loop

  • • Class-keyed applicator: routes by motion class, not layer name
  • • MLS / ARAP mesh warp: large, natural, no tearing
  • • Auto-tune: apply → render → judge → Δ → repeat ×2–3
  • • Contracts A/B/C decouple the three streams
